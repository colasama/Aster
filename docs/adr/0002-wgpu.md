# ADR 0002: wgpu as the native graphics abstraction

- Status: accepted
- Date: 2026-08-20

Use wgpu for native Vulkan, Metal, and DX12 portability, with WebGPU for the browser preview. Aster
needs explicit resources and compute without committing its architecture to one vendor. Backend-
specific acceleration may be optional, but project semantics and the baseline renderer cannot depend
on CUDA or a single operating system.
