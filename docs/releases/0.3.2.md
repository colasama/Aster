Aster 0.3.2 is a desktop release.

## Downloads

- **macOS:** DMG and ZIP for Apple Silicon (arm64) and Intel (x64).
- **Windows:** x64 NSIS installer.
- **Linux:** x64 AppImage and Debian package.
- **SHA256SUMS.txt:** SHA-256 checksums for all seven installation files.

## Changes

- Hold the previous preview frame while media decodes, prefetch still images on import and project open, and prepare upcoming layers ahead of the playhead so loading media never flashes a placeholder color.
- Render missing media layers as magenta placeholders in preview and export.
- Rasterize precompositions containing cameras instead of flattening them.
- Retain text rasters across frames whenever the evaluated glyph state is unchanged.
- Speed up blur and glow-family effects with a shared GPU downsample pyramid and masked bright-pass accumulation.
- Add italic text and complete transform controls in the inspector.
- Expose per-format output options in the render queue form.
- Add transactional bulk editing and isolated MCP script execution.
- Allow sanitized clipboard writes in the editor window.
- Keep timeline zoom gestures off the React tree, cache hot-path evaluation, and overlap export readbacks.
- Release blocked encoder audio writes when an MP4 export is cancelled, and fix precision-degrading shader hash functions.
- Polish studio surfaces and motion; highlight context menu entries on hover.
- Ship separate Apple Silicon and Intel macOS packages.

## Notes

These packages are unsigned. The macOS app has an ad-hoc signature and is not notarized by Apple.
Bundled media tools use the GPL-enabled preview configuration; build provenance and upstream notices are included with the application.
The project format and plugin API are still pre-1.0 and may change between 0.x releases. Keep backups of projects before upgrading.
