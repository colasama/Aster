Aster 0.3.4 is a desktop release.

## Downloads

- **macOS:** DMG and ZIP for Apple Silicon (arm64) and Intel (x64).
- **Windows:** x64 NSIS installer.
- **Linux:** x64 AppImage and Debian package.
- **SHA256SUMS.txt:** SHA-256 checksums for all seven installation files.

## Changes

- Add high-performance and power-saving GPU selection in Preferences. High performance is the default; changing GPUs takes effect after restarting Aster.
- Default anti-aliasing to Off for profiles without a saved choice, preserving existing preferences.
- Fix Windows unified GPU memory detection and memory-budget reporting.
- Route toolbar rendering through the background render queue and acknowledge saved jobs without waiting for render-host preparation.
- Show an adding state while capturing and saving a render job, and space the Cancel and Add buttons consistently.
- Recapture exports when pending media keeps the discovery frame from being ready.

## Notes

GPU selection depends on the platform and available hardware; it selects a performance preference rather than a specific adapter by device ID.
These packages are unsigned. The macOS app has an ad-hoc signature and is not notarized by Apple.
Bundled media tools use the GPL-enabled preview configuration; build provenance and upstream notices are included with the application.
The project format and plugin API are still pre-1.0 and may change between 0.x releases. Keep backups of projects before upgrading.
