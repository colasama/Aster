Aster 0.3.5 is a desktop release.

## Downloads

- **macOS:** DMG and ZIP for Apple Silicon (arm64) and Intel (x64).
- **Windows:** x64 NSIS installer.
- **Linux:** x64 AppImage and Debian package.
- **SHA256SUMS.txt:** SHA-256 checksums for all seven installation files.

## Changes

- Add text animation presets, correct range-selector easing and smoothness, and anchor presets to their start delay.
- Fix the "Text selector property does not exist" error when expression selectors omit their optional time offset, including migrated projects.
- Keep the timeline playhead out of the fixed property column when scrolling horizontally, dragging, or snapping.
- Add After Effects-style timeline editing, refresh the purple theme, and improve editor panels, selection, document handling, and the agent panel.
- Consolidate the MCP automation tools and add camera fitting, composition cleanup, footage relinking, and labeled preview contact sheets.
- Add beat analysis with composition markers and beat expressions, plus expressions for effect parameters.
- Fix black frames in video-synchronized captures and report black output frames.
- Preserve saved edits during delayed startup restoration and keep idle workspaces available.
- Correct hex-color conversion to linear light for non-text layers. This can change rendered colors compared with 0.3.4.
- Restore frontend and Rust test execution in the desktop release quality gate.

## Compatibility and packaging

The MCP tool surface has changed; external agents should refresh their tool discovery.
Project schema version 10 and the existing migration range (versions 1 through 9) are unchanged.
These packages are unsigned. The macOS app has an ad-hoc signature and is not notarized by Apple.
Bundled media tools use the GPL-enabled preview configuration; build provenance and upstream notices are included with the application.
The project format and plugin API are still pre-1.0 and may change between 0.x releases. Keep backups of projects before upgrading.
