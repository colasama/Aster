Aster 0.3.1 is a desktop preview release.

## Downloads

- **macOS:** Universal DMG and ZIP for Apple Silicon and Intel.
- **Windows:** x64 NSIS installer.
- **Linux:** x64 AppImage and Debian package.
- **SHA256SUMS.txt:** SHA-256 checksums for all five installation files.

## Changes

- Preserve imported image colors throughout preview and export.
- Display text outside its paragraph box without clipping or horizontal squeezing, including animated text, strokes, blur, precompositions, and export.
- Expand the inline text editor vertically as text grows while preserving paragraph layout and layer anchors.
- Detect available memory on the rendering GPU. Automatic mode subtracts 1 GiB from free memory and rounds down to whole GiB, with a conservative fallback for low or unavailable memory readings.
- Allow manual GPU budgets up to detected device capacity, with explicit refresh and a warning when the budget exceeds currently free memory.
- Apply saved GPU budgets consistently to preview and isolated export rendering.

## Preview notes

Free-memory detection depends on platform and driver support. macOS currently uses a conservative automatic fallback; Apple silicon capacity is labeled as shared system memory. GPU budgets guide allocation planning and do not reserve physical memory.

These packages are unsigned previews. The macOS app has an ad-hoc signature and is not notarized by Apple.
Bundled media tools use the GPL-enabled preview configuration; build provenance and upstream notices are included with the application.
The project format and plugin API are still pre-1.0 and may change between 0.x releases. Keep backups of projects before upgrading.
